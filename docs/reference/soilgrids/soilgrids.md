# SoilGrids — API reference

ISRIC SoilGrids 2.0 soil-property backend subpackage — `earthlens.soilgrids`.
Background and usage are covered under the other pages in this section
([Introduction](introduction.md), [Usage](usage.md),
[Available properties](datasets.md)); this page is the rendered API. SoilGrids
is public / CC-BY 4.0, so there is no `auth` module, and the WCS transport lives
in [pyramids](https://github.com/serapeum-org/pyramids)
(`Dataset.from_wcs`) — earthlens imports no OGC-WCS SDK.
