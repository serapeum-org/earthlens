# PVGIS — API reference

`earthlens.pvgis`. Background and usage are covered under the other pages in
this section ([Introduction](introduction.md), [Usage](usage.md),
[Available products](datasets.md)); this page is the rendered API. PVGIS is a
keyless REST API, so there is no `auth` module.
