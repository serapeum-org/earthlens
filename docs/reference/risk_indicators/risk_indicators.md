# Risk indicators — API reference

Country / admin-indexed risk-indicator backend subpackage —
`earthlens.risk_indicators`. Background and usage are covered under the other
pages in this section ([Introduction](introduction.md), [Usage](usage.md),
[Available datasets](datasets.md)); this page is the rendered API. Auth is
**per source** — only the GFW datasets use the `auth` module
(`GfwAuth` / `GfwCredentials`); ThinkHazard! and INFORM are public.
