# Brand & media kit

Everything you need to represent **earthlens** in docs, on GitHub and PyPI, or on social media. Every asset below
ships in the repository under `docs/_images/branding/earthlens-brand-kit/`.

[:material-folder-download: Browse the kit on GitHub](https://github.com/serapeum-org/earthlens/tree/main/docs/_images/branding/earthlens-brand-kit){ .md-button .md-button--primary }

## The mark

A satellite captures Earth-observation data, which resolves down through a pyramid of raster overview tiles — the
[pyramids](https://github.com/serapeum-org/pyramids) lineage — onto a living, rotating globe. The name is the
story: **earth + lens**.

The animated logo is a **self-contained SVG** — the motion is CSS `@keyframes` inside the file, with no
JavaScript — so it animates inside a plain `<img>` and weighs 14.5 KB. Prefer it over the GIFs wherever a vector
will do.

`favicon/` holds `favicon.ico` (48×48) plus PNGs at 16, 32, 48, 64, 180, 192 and 512 px, and
`apple-touch-icon.png` (180×180). Wire them up with:

```html
<link rel="icon" href="favicon/favicon.ico" sizes="any">
<link rel="icon" type="image/png" href="favicon/favicon-32.png">
<link rel="apple-touch-icon" href="favicon/apple-touch-icon.png">
```

This site uses `favicon-32.png`, set through `theme.favicon` in `mkdocs.yml`.

## Typography

- **Wordmark and headings** — Outfit (Bold). The wordmark is `earth` in light or navy, `lens` in gold.
- **Taglines and code** — Geist Mono / DM Mono.

## Clear space, and what not to do

Keep clear space of at least the satellite's height around the mark.

Do not recolor the wordmark, stretch the mark, or drop the transparent logo onto a busy photo without a navy
scrim behind it.
